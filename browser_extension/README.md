# server-kit 本地密钥生成器

这是一个完全离线的 Manifest V3 扩展。它不申请网站访问权限，不连接 VPS，也不保存审批身份。

使用流程：

1. 从 server-kit 管理网站复制“服务器公开参数”。
2. 在扩展中粘贴参数，填写节点名称并本地生成。
3. 把扩展输出的“节点登记信息”粘贴回管理网站确认。
4. 下载、复制或扫描任一 AWG 配置。

AWG 客户端私钥只在当前页面生成配置；登记信息只包含名称、虚拟 IP、公钥和预共享密钥。临时配置最多保存在浏览器会话内存 5 分钟，也可以导出带口令的 AES-256-GCM 恢复包。

开发时在 Chrome 或 Edge 的扩展管理页选择“加载已解压的扩展程序”。可复现构建方法见 `RELEASE.md`。
