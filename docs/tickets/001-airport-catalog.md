# 票据 001：机场资源目录

状态：已完成

## 目标

将单个 `airport_url` 深化为支持多个机场的事实目录，并兼容既有 version 2 配置。

## 验收

- 支持新增、修改、删除多个机场。
- 每个机场保存稳定标识、名称、启用状态和国家/地区选择。
- 概览不返回订阅链接或令牌。
- 既有单机场配置可无损读取，并在首次写入时迁移。
- 事实文件继续以 root-only、原子替换方式保存。

## 完成证据

- `lib/server_kit_proxy_resources.py` 提供 version 3 多机场目录、脱敏概览和 version 2 迁移。
- `tests/test_proxy_resources.py` 覆盖新增、修改、停用、删除、重复名称、迁移及凭据脱敏。
