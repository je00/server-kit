# 票据 003：机场变更任务与健康观测

状态：已完成

## 目标

收口机场目录变更、订阅刷新、失败回滚和多机场健康检查。

## 验收

- 新增、修改、删除机场及更新出口均通过持久化变更任务。
- 敏感链接不进入普通任务参数、预览、日志或审计。
- Clash 刷新失败时恢复原事实配置。
- 健康检查逐机场返回脱敏结果，并允许部分失败。

## 完成证据

- `network.proxy.update` 只把非敏感目录意图写入普通任务参数，链接和出口 YAML 使用任务密文。
- `server-kit-manager.sh` 在刷新失败时恢复原事实文件。
- Runner、ControlPlane 和资源 module 测试覆盖固定参数、审计脱敏、目标校验和部分失败。
