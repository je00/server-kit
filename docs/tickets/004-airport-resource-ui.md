# 票据 004：机场资源网页

状态：已完成

## 目标

将“代理资源”改为“机场资源”，提供适合桌面与手机的多机场管理体验。

## 验收

- 导航、标题和说明统一使用“机场资源”。
- 可添加多个机场，并可修改或删除。
- 每个机场可勾选启用状态和国家/地区。
- 页面显示逐机场脱敏状态和连通性结果。
- 变更继续经过密码确认、影响预览和异步任务。

## 完成证据

- 导航、部署向导、发布订阅入口及资源页已统一为“机场资源”。
- 页面提供逐机场折叠编辑、启用开关、国家/地区复选、新增、删除、出口维护与整体测试。
- Django 测试覆盖多机场脱敏展示、新增和选择更新；移动端断点改为单列编辑与双列国家选择。
