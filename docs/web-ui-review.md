# 管理网页本地验收

本文记录网页与交互改进的本地验收。审查期间没有连接或部署 VPS，没有修改线上 AWG、SSH、Xray、防火墙、DNS 策略或订阅事实配置。Git 提交和推送不等于上线部署。

## 主要改进

- 统一暖白／石墨／天蓝主题、铜橙强调色、图标导航、信息层级与表单样式。尊重已保存主题，新访客默认亮色。
- 手机导航收敛为总览、内网节点、代理资源、更多；完整菜单、主题、账号和退出操作均可达。矮屏侧栏可滚动。
- 修复窄屏固定列宽、长名称/指纹、SSH 改名输入、危险按钮样式、弹窗高度和底栏遮挡；输入字号避免手机自动放大。
- 节点、机场、出口支持即时搜索；长页面提供页内入口；危险操作折叠并保留确认、密码及权限检查。
- 内网权限默认指定 TCP，而非全部协议；支持已有的单端口、范围与混合格式。示例 YAML 不再预填为待提交配置。
- 已停止/失败的已安装服务提供排查入口，不再引导重复安装。
- 任务页只轮询更新内容，支持暂停，选择文字或操作控件时暂缓更新；失败原因与回滚确认窗口前置。
- 读取失败不再伪装为零资源或空闲状态；独立事实分别显示错误，保留仍可读取的任务、备份和待确认恢复事务。
- 弹窗支持 Escape、Tab 焦点循环和关闭后焦点恢复；失败反馈持续可见；重复提交保护保留按钮的操作参数。
- 临时客户端配置按五分钟期限清理，处理禁用/损坏浏览器存储及退出登录清理；不修改服务端密钥流程。

## 本地复现

使用安装了 `web/requirements.txt` 的 Python 环境：

```sh
python tests/run_web_preview.py
```

打开 `http://127.0.0.1:8765/__preview__/`，演示账号 `preview`，密码 `Preview-only-2026!`。只读账号 `viewer` 使用相同演示密码。

预览强制监听本机，创建独立临时数据库、密钥和 Unix socket，使用合成域名/文档 IP；所有管理动作由内存替身处理。不要在其中输入真实凭据或上传真实敏感文件。

场景与浏览器审查命令见 [本地预览说明](../tests/preview_README.md)。生产路由不包含演示入口。

## 追加优化：权限同页批量添加

- 单个来源节点一次填写 1–20 条规则，可混合不同目标、TCP、UDP 和全部协议，端口支持逗号与范围。
- 同页统一预览、返回编辑、确认及显示结果；只有确认才排队执行。无 JavaScript 时保留原有单条确认页。
- 只追加新规则，整批校验后一次应用；沿用后台事实核验、队列幂等确认与管理入口保护。已有权限不删除，AWG 接口不重启。
- 成功后只更新当前节点权限列表，不刷新整页，不清空其他节点草稿；出错保留本次输入。
- 确认响应丢失时只查询原任务，不自动重新提交；权限列表读取失败时显示已成功但待核验，不伪造最新列表。
- 演示和回归仅使用临时文件、内存替身与本地浏览器；未在 VPS 上运行权限变更。
- 追加回归：网页 145 项、后端与权限应用/恢复 188 项、前端隐私和隔离预览 38 项通过；Chromium/WebKit 覆盖桌面、390px 手机和 320px 窄屏，包含断线、重复点击、草稿保留及 44px 触控检查。

## 第二轮：减少跳页与输入丢失

- 机场／出口增改删、节点出口选择、内网域名映射及权限撤销改为同页预览、确认、跟踪结果。保留原有密码核验、管理员权限和后台任务机制；服务启停、入口变更、备份恢复等高风险流程不绕过确认。
- 校验失败保留表单；保存只更新对应列表，其他行草稿、搜索条件和展开状态不丢失。新增出口成功后正确恢复字段输入模式；删掉最后一条权限后仍可原地批量添加。
- 确认响应丢失只查询原任务，不自动重提。列表快照缺失或读取失败时保留原记录，提示重新读取，不能把错误响应当作空列表。
- 代理／文件敏感信息解锁失效后，弹窗验证并继续原操作，无需刷新整页；不把密码、订阅凭据或 YAML 保存到浏览器存储。
- 管理账号支持同页创建、改密、启停；错误保留输入，成功仅清除本次密码。展开表单不再覆盖其他账号；修改自身密码保留当前登录会话。
- 文件上传显示实际进度，并区分传输、服务端校验和任务排队；整个请求期间防止重复提交，结果不明时先核验任务记录。
- 任务详情提供返回来源页面的入口；只记允许的页面标识，不接受任意返回网址。备份恢复预览增加明确的“不应用，返回列表”入口。
- 本轮继续仅用本机伪数据验证，没有连接或部署 VPS。DNS 策略、国内直连配置与线上内网服务保持不变。
- 最终回归：178 项网页测试、42 项前端／隐私／隔离预览测试、40 页面渲染通过；另通过 20 组同页操作浏览器场景、22 项上传交互检查和双引擎账号操作检查。未发现脚本异常、外部请求或横向溢出。

## 手机渲染修正：检查组件内部溢出

- 用户截图中的主题按钮越框已在 Chromium / WebKit 复现：旧样式把容器固定为约 40.8px，新按钮最小高度为 44px，加上内边距后向下溢出约 7.4px。移除固定高度及旧横向导航遗留尺寸，让容器随按钮自适应。
- “更多已展开”与“当前页面”使用不同的底色／描边，底部各项增加间距，不再看似同时选中两页。
- 修正同类选择器优先级冲突：节点中转设置、公网入口、动态 DNS、备份按钮在手机上统一至少 44px；菜单关闭、退出按钮同样保留触控空间。
- 菜单内长账号名可折行且不挤压退出按钮，滚动区域增加边缘防穿透保护；保留矮屏滚动和主题切换功能。
- 补测发现 320×430 登录页滚动至提交按钮时，固定主题条会遮挡用户名输入框；手机登录主题条改为正常文档流，随页面滚动，不再盖住表单。
- 新增 `tests/run_mobile_render_ui.cjs`，除了整页横向溢出，还检查按钮是否超出自身容器，避免重复漏掉这类局部渲染问题。本轮修正先在本地合成数据验证，不修改 VPS。
- 验证结果：移动专项 Chromium / WebKit、三种主题、六种视口共 2,926 项断言通过，生成 90 张截图；40 页四种宽度视觉巡检无横向溢出或脚本异常，另有 178 项后端及 42 项前端／预览测试通过。尚未进行真实 iPhone 验收。
