安全底线

一机一份每台设备使用自己的节点、订阅和 SSH 密钥。

私钥不外发只复制 .pub 公钥，私钥永远留在生成它的设备上。

丢失就撤销删除节点、轮换订阅令牌，并删除该设备对应的 SSH 公钥。
